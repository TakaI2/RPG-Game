RPG Game Tools

ゲームデータを編集するエディタ一覧。「ゲームに保存」ボタンで public/assets/ に直接書き込めます。

エディタ
👾
Enemy Editor
敵キャラクターの定義（HP・速度・AI・セリフ）を編集します。
保存先: assets/enemies/enemy-defs.json
🗺️
Gameflow Editor
マップ・ストーリー・BGMの遷移フローをノードグラフで編集します。
保存先: assets/gameflow.json
💬
Story Editor
ストーリースクリプト（セリフ・背景・BGM・SE）を編集します。
保存先: assets/story/scripts/{id}.json
🏗️
Map Editor
タイルマップ・敵/NPCスポーン・ポータルを配置します。
保存先: assets/maps/{mapId}.json
🧑
NPC Editor
NPCの定義（スプライト・アニメ・移動・セリフ）を編集します。
保存先: assets/npcs/npc-defs.json
🧱
Tileset Editor
タイルセット定義（画像・ロール・アニメ設定）を管理します。
保存先: assets/maps/tilesets.json
