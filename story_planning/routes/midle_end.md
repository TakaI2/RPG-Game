# ルート：中間エンディング（midle_end.json）

## 概要

grave_map での戦闘後、リアラを完全には倒せず逃げられてしまった結末。
ベルナデットが悔しがる中、ルーネが父親のことを打ち明け、2人で城へ乗り込むことを決意するシーン。
本作（第一部）の実質的なエンディングで、続編（ベラドンナ戦）への橋渡しとなる。

**対応ファイル：** `assets/story/scripts/midle_end.json`
**トリガー：** grave_map の onBossDefeat
**次の遷移：** exit（続編へ）

## 現状のシーン流れ

1. ベルナデット、リアラに逃げられて悔しがる
2. ルーネがまだそこにいることに気づく
3. ルーネが父親の被害を打ち明ける（村の犠牲者の中にいた）
4. ベルナデット、焼き払えないと内心思いながらルーネを連れていくことにする
5. 一緒に城へ行こうと誘う
6. ルーネが怖いながらも決意する
7. 「冒険といきましょうか！」で締め

## 拡充案

### 追加したいシーン

**Scene 0（冒頭に追加）：リアラ逃走の瞬間**

```
リアラ：くっ・・・！　この・・・！
リアラ：覚えてなさい！　ベラドンナ様に言いつけてやる！！
ベルナデット：あ、逃げた！
（SE：羽ばたく音、蝙蝠に変身して飛び去る演出）
ベルナデット：追えない・・・速い！
```

→ 既存のベルナデットの悔しがるセリフにつながる

**Scene 中（父親の話の後に追加）：**

ベルナデット：保証はできないけど、やってみる価値はあるわ。
ルーネ：・・・じゃあ、行かないわけにはいかない。
```

```
ルーネ：（ベラドンナって・・・どんな人なんだろう。）
ナレーション：2人の長い旅が、ここから始まった。

## キャラクター上の重要性

- ルーネの**父親が犠牲者**だったことが判明 → 彼の戦う動機が明確になる
- ベルナデットが「面倒くさいけど放っておけない」という人間性を見せる重要シーン
- 「お姉ちゃんについてきていいよ！」 → 2人の関係が一歩進む
- 「親玉を倒す」＝ベラドンナへの言及 → 続編の目標が設定される
