# ルート：トゥルーエンド（clear.json）

## 概要

続編（第二部）でベラドンナを撃破した際の真エンディング。
現時点の `clear.json` は世界観が全く異なるプレースホルダーのため、**丸ごと書き直しが必要**。

**対応ファイル：** `assets/story/scripts/clear.json`
**トリガー：** （続編）ベラドンナボス戦の onBossDefeat
**次の遷移：** exit

> ⚠️ 現状の `clear.json` は「魔女・神父・勇者」という別世界観の内容。本作のキャラクターは一切登場しない。本ドキュメントは書き直し後の目標案。

```
第一部（本作）  → onBossDefeat → [midle_end]（リアラ逃走・城へ）
```

3. **第二部実装時**：本ドキュメントの案で本格的に書き直す
