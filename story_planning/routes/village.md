# ルート：村の探索（Village_map）

## 概要

オープニング後に始まるゲームパート。
ベルナデットとルーネが制圧された村を探索し、サキュバスを倒しながらリアラのいる墓地を目指す。

**対応マップ：** `Village_map`
**BGM：** spiral
**次の遷移：** ポータル → grave_map（x=5, y=5）

---

## マップの状況

村はサキュバス軍団によって制圧されており、男性住民の多くが虜囚状態。
廃墟やがれき、フェンスが散乱する惨状。

### 配置NPC・オブジェクト（既存）

| NPC | 状態 | セリフ |
|-----|------|--------|
| 村人 | 正気 | 「この先には魔物がいるから気をつけて！」|
| 生贄 | 虜囚 | 「うううぅ・・・・」 |
| 犠牲者1 | 廃人化 | 「あ・・・、あぁ・・・」「すって・・・、もっと・・・、もっと・・・」 |
| フェンス1・2 | 障害物 | — |
| がれき1・2・3 | 障害物 | — |
| 炎 | 装飾 | — |

## 探索中のドラマ案

### 犠牲者との遭遇

プレイヤーが犠牲者に話しかける → **priest_eventを流用 or 専用台詞**

```
ルーネ：（これは・・・村の人が・・・）
ベルナデット：サキュバスに養分を吸い尽くされた人間よ。
ベルナデット：理性は残ってないわ。このまま放っておけば、いずれ廃人になる。
ルーネ：そんな・・・！！　なんとかならないんですか！！
ベルナデット：リアラを倒せば眷属の繋がりが切れる。そうしたら自力で戻れるかもしれない。
ベルナデット：ってわけで、さっさと先を急ぎましょ。
```

### 正気の村人との会話

```
村人：あんたたち、逃げた方がいい！　先には化け物がいる！
ルーネ：知ってます。でも、みんなを助けたいんです。
村人：馬鹿な・・・あの吸血鬼には勝てないよ。止めておけ。
ベルナデット：ありがとうございます、ご忠告。参考にします。
```

### ルーネの自問自答（ベルナデットに話しかけるサブイベント案）

```
ルーネ：ベルナデットさん・・・怖くないんですか？
ベルナデット：怖いに決まってるじゃない。吸血鬼なんて化け物相手に怖くなかったら、それはただのバカよ。
ルーネ：でも、全然そう見えない。
ベルナデット：見せないようにしてるの。怖がってる姿を見せたら、こういう場所では死ぬから。
ルーネ：・・・・
ベルナデット：行くわよ。墓地はこの先ね。
```

## ゲームフロー

1. Village_map に出現するサキュバス系エネミーを倒しながら進む
2. マップ内のポータルに触れる
3. → grave_mapへ遷移
4. grave_map onEnter → **boss_story** 再生
5. → ボス戦（リアラ）

---

## 追加検討事項

- 神父（priest）イベントをVillage_mapに配置するか検討
  - 現状の `priest_event.json` は世界観が異なるため、村の神父として書き直しが必要
  - 例：教会に避難している神父が、墓地の危険と道順を教えてくれる
- 村の奥に進むほど被害が酷くなる演出（がれき・炎・犠牲者が増える）
- 「ルーネを連れての探索」というコンセプトのため、戦闘中にルーネが怖がる台詞を出すのも◎
