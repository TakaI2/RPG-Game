# ルート：オープニング（opening.json）

## 概要

ゲームの導入部。夜の村を舞台に、ルーネがサキュバスに追われる場面から始まる。
ベルナデットがリアラと遭遇し、マントを巡る因縁が生まれる。

**対応ファイル：** `assets/story/scripts/opening.json`
**次の遷移：** Village_map（x=10, y=10）

---

## 現状の問題点

- 背景画像なし（`bg` コマンドが存在しない）
- 立ち絵なし（`portrait` が使われていない）
- キャラクターの掘り下げが薄い
- `end` コマンドあり ✅（遷移は正常に機能する）

## 拡充案：シーン構成

### Scene 1：逃走（BGM: 緊張感のある曲）

**背景：** 夜の村、炎が上がっている廃墟（`bg` で設定）

```
ルーネ：はぁ・・・、はぁっ！！
ルーネ：（心の中）どうして・・・どうしてこんなことに・・・！
ルーネ：みんなが、みんな壊れていく・・・！！
ルーネ：早く逃げなきゃ・・・！！
```

### Scene 2：追い詰められる

**背景：** 墓地の入口、月明かり

```
サキュバス：みつけたよ～♥
サキュバス：どこに逃げても無駄だよ？　おとなしくしてたら、気持ちよくしてあげるのに。
ルーネ：ひっ・・・！　く、来るな！！
```

### Scene 3：リアラ登場

**立ち絵：** リアラ（右側）

```
リアラ：ふふふ・・・♥　どこへ逃げるつもり？　ボウヤ。
ルーネ：！？
リアラ：み～つけた♥
ルーネ：ひぃぃっ！？
リアラ：村にいる男達は、もうみんな私のかわいいコ達の玩具よ。
リアラ：君みたいに、若くて美味しそうなボウヤを味わわずに帰れないわ。
ルーネ：たすけて・・・。
```

### Scene 4：ベルナデット登場

**SE：** 軽快な足音 or 登場効果音

```
ベルナデット：お～っと、早速獲物発見した？
リアラ：なに・・・？
ベルナデット：どうも～！！　安らかに眠れない貴方の為に、迅速に安らぎをお届けです！
リアラ：・・・ヴァンパイアハンター？
```

### Scene 5：マントを巡る因縁

```
リアラ：っ！！　あなた、そのマントは・・・！！
リアラ：だから気配が感じ取れなかったのか・・・。
リアラ：私の同胞を殺して奪ったのね・・・！！
ベルナデット：おかげさまで、気に入っているの。　魔物たちには同類だと思ってもらえるし、上等なのは着心地も良いからね。
ベルナデット：貴女のも上等そうね、大きいしツルツルしてて気持ちよさそう♥
リアラ：っ・・・！！
ベルナデット：吸血娘のマントは好事家に高く売れるし、それだけ良い物なら私のコレクションに加えてもよさそう！
リアラ：冗談じゃない！！
リアラ：お姉様から贈って頂いた大事なマントを、貴女なんかに！！
```

### Scene 6：戦闘前宣言

```
リアラ：獲物になるのは貴女よ！　私の可愛いサキュバス達の餌食になるといいわ！
リアラ：ボウヤもね！　私が可愛がってあげようと思ったのに。
リアラ：嫌だと言うならその女と仲良く、全員まとめて吸い尽くしてあげる！！
ルーネ：ベルナデットさん・・・！
ベルナデット：（ルーネに向かって）後ろにいて。前に出ちゃダメよ。
ルーネ：で、でも・・・
ベルナデット：大丈夫。こういう仕事、慣れてるから。
```

**→ end / ゲームパートへ**

## 追加検討事項

- オープニング中は背景として「燃える村」や「夜の墓地」の画像が欲しい
- リアラ・ベルナデットの立ち絵を表示するとより映える
- BGMは `redmoon.ogg` が雰囲気に合いそう（緊迫感ある曲調であれば）
- ルーネが村に残った理由を1行添えるとキャラクターに深みが出る
