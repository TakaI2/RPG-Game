# ルート：ボス対決（boss_story.json）

## 概要

Village_mapを突破したベルナデットとルーネが、grave_map（墓地）へ到達。
リアラとの最終対決前の会話シーン。

**対応ファイル：** `assets/story/scripts/boss_story.json`
**トリガー：** grave_map の onEnter
**次の遷移：** ストーリー終了後 → ボス戦（reala_boss）

## 拡充案：シーン構成

### Scene 1：墓地到着

**背景：** 墓地（深夜）、月が高い

```
ルーネ：ここが・・・墓地。
ベルナデット：気配がするわ。いるはずよ。
ルーネ：（ベルナデット、少し立ち止まって聞いてくれ、という気持ちで）ベルナデットさん。
ベルナデット：なに？
ルーネ：あなたは・・・いつも一人でこういうことを？
ベルナデット：大体ね。今日は君が一緒だけど。
ルーネ：僕、役に立てなくてすみません。
ベルナデット：助けてって叫ぶだけでも十分役に立ってるわよ。やることが増えると集中できる。
```

### Scene 2：サキュバスの報告

```
サキュバス：リアラ様～。止められませんでした～！
サキュバス：あのハンター、強すぎて・・・！
リアラ：ちっ・・・、せっかくのディナーが台無しだわ！

### Scene 3：リアラ登場

**立ち絵：** リアラ（右側、不機嫌な表情）

```
リアラ：（ため息）・・・仕方ないわね。
リアラ：そう、そんなに私達に逆らいたいのね。
リアラ：来るのが遅かったじゃない。もう少しで帰るところだったのに。
ベルナデット：それは残念。わざわざ待っていてくれなくてよかったのに。
リアラ：（目を細めて）貴女・・・やっぱり気に食わないわ。
リアラ：私のサキュバスを何人やったと思ってるの。
ベルナデット：数えてないけど、そこそこ？
```

### Scene 4：マントへの怒り再燃

```
リアラ：そのマント・・・返しなさい。
ベルナデット：嫌よ。気に入ってるもの。
リアラ：っ！！

ベルナデット：あら、その「お姉様」って人にもマントが欲しくなってきたわ。上等そう。

```

### Scene 5：決戦宣言

```
リアラ：2人とも、血も精気も吸い尽くしてあげる！！　覚悟しなさい！
ルーネ：ベルナデットさん・・・！
ベルナデット：聞いてた。大丈夫よ。
ベルナデット：（小声で）ルーネ、絶対に後ろに下がってなさい。いいわね。

## ボス戦の結末（midle_end との接続）

本作（第一部）では、リアラは完全には倒れず**逃走する**。
これが `onBossDefeat → midle_end` への流れとなる。

ゲーム上は「プレイヤーがボスのHPを0にした」＝ボス撃破扱いだが、
ストーリーとしては「手傷を負わせて逃げられた」という解釈で一貫させる。

> リアラの `defeat` セリフ「ベラドンナ様に言いつけてやる！！」は
> midle_end の冒頭で蝙蝠に変身して飛び去る演出と合わせると自然につながる。
