# キャラクタープロフィール：ベルナデット

## 基本情報

| 項目 | 内容 |
|------|------|
| 名前 | ベルナデット |
| 年齢 | 20代前半（推定） |
| 職業 | ヴァンパイアハンター |
| 役割 | プレイヤーキャラクター |

## 外見

- 長身でスラリとした体型
- 吸血鬼から奪い取ったマント（光沢のある黒）を羽織っている
- 戦闘向きの動きやすい服装
- 表情は飄々としており、常にどこか余裕がある

## 性格

- 軽口が多く、物事を深刻に考えない素振りを見せる
- 実際は腕の立つ実力者で、感情的にならず冷静に状況を判断できる
- 金と戦利品にこだわる"商売人"的な側面がある
- しかし民間人が危険にさらされると放っておけない
- 強い魔物の装備品を集めるコレクター癖がある
- 言葉遣いはくだけていて親しみやすいが、一線を引いている

## 背景・動機

- 吸血鬼の死体から奪った漆黒のマントを着用。これにより魔物に「同類」と誤認させる戦術を取る
- ヴァンパイアハンターとして各地を渡り歩いており、リアラ討伐はある意味「たまたま居合わせた」依頼
- リアラのマントも「上等そう」と興味を示しており、戦利品として狙っている
- 深い過去や動機は明示されていないが、吸血鬼に対する個人的な感情がある可能性を示唆できる

## 主要なセリフ（既存）

- 「どうも～！！　安らかに眠れない貴方の為に、迅速に安らぎをお届けです！」
- 「おかげさまで、気に入っているの。魔物たちには同類だと思ってもらえるし、上等なのは着心地も良いからね。」
- 「貴女のも上等そうね、大きいしツルツルしてて気持ちよさそう♥」
- 「吸血娘のマントは好事家に高く売れるし、それだけ良い物なら私のコレクションに加えてもよさそう！」

## キャラクター上の役割

- ゲームプレイの主体（プレイヤー操作）
- ルーネとのコンビによるドラマを形成
- リアラとは戦利品（マント）を巡る因縁でキャラクター的な対立軸を持つ
- ベラドンナへの対決が最終的なゴールになる可能性
