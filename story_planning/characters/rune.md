# キャラクタープロフィール：ルーネ

## 基本情報

| 項目 | 内容 |
|------|------|
| 名前 | ルーネ |
| 年齢 | 17〜18歳（推定） |
| 職業 | 村人（普通の青年） |
| 役割 | 非戦闘NPC・コンビの片割れ |

## 外見

- 細身で若い青年
- 普通の村人の服装
- 怯えた表情が基本だが、芯の強さをたまに見せる

## 性格

- 臆病で慌てやすい
- 戦闘経験はゼロ、魔物との戦い方は知らない
- しかし根は真面目で、ベルナデットに迷惑をかけたくという気持ちがある
- 状況に流されやすいが、大切な人を守る局面では奮起する
- ベルナデットに対して敬意と若干の情を抱いていく

## 背景・動機

- Village_mapの住人。サキュバスに村を制圧される前から暮らしていた
- リアラたちに追われていたところをベルナデットに助けられる
- 村の他の男たちはすでにサキュバスたちに虜にされており、正気を保つ者が少ない
- 逃げ出せなかった理由は「村に残った家族や友人を見捨てられなかった」から（セリフで示唆可）
- 戦う力はないが、ベルナデットのサポート役として行動を共にする

## 主要なセリフ（既存・拡充案）

**既存：**
- 「はぁ・・・、はぁっ！！」（必死に逃げる）
- 「どうしてこんなことに・・・！　早く逃げなきゃ・・・！！」
- 「ひぃぃっ！？」（リアラに捕まりかける）
- 「たすけて・・・。」

**拡充案：**
- 「ベルナデットさん、あなたは本当に怖くないんですか・・・？」
- 「僕には戦う力なんてない。でも、このまま逃げるだけなんて・・・」
- 「村のみんなを取り戻せるなら、何だってします！」

## キャラクター上の役割

- バッドエンドでは最終的な被害者として描かれる（リアラに捕まる）
- クリアルートでは村の解放を喜ぶ存在、ベルナデットとの別れのシーンを担う
- ベルナデットの「放っておけない」という性質を引き出すトリガー
- プレイヤーが守るべき対象として感情移入の軸になる
