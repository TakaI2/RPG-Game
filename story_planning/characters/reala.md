# キャラクタープロフィール：リアラ

## 基本情報

| 項目 | 内容 |
|------|------|
| 名前 | リアラ |
| 種族 | 吸血鬼（ヴァンパイア）|
| 年齢 | 不詳（外見は20代） |
| 肩書き | 吸血鬼の貴族、サキュバス軍団の指揮者 |
| 役割 | メインボス・ゲームの主な敵 |
| 上位者 | ベラドンナ（お姉様）|

## 外見

- 妖艶で美しい吸血鬼の女性
- 漆黒のマント（お姉様＝ベラドンナから賜った大切な品）
- 蝙蝠のモチーフが散りばめられた衣装
- HP低下時（フェーズ2）で表情が険しくなる

## 性格

- 普段は余裕綽々の優雅なヴァンパイア貴族
- 若い男性を好み、「可愛がる」という表現を使う捕食者的な嗜好
- 怒ると残酷さが表に出る。特にマントへの言及は地雷
- 自分の「お姉様」であるベラドンナを深く慕っており、その名を出すことで感情が揺れる
- 敗北を認めたくない自尊心の強さがある
- 部下のサキュバスたちに対しては愛情と道具的な扱いが混在

## 背景・動機

- ベラドンナ配下の吸血鬼貴族として村を制圧しに来た
- 目的は村の男性から血と精気を奪うこと、美味しそうな獲物を確保すること
- マントはベラドンナから直接贈られた宝物であり、ベルナデットに狙われていることに激怒している
- 本作での敗北後は「ベラドンナ様に言いつける」と捨て台詞を吐いて撤退 → ベラドンナ戦の布石

## 攻撃パターン（ゲーム内）

| 技名 | 説明 |
|------|------|
| テンプテーション | ハート型の弾を6方向に放射する妖惑攻撃 |
| 支配のキス | テレポートしてプレイヤーに接近→突進 |
| 蝙蝠（フェーズ2のみ） | 蝙蝠型の弾を螺旋状に16発展開する必殺技 |

## 主要なセリフ（既存）

- 「ふふふ・・・♥　どこへ逃げるつもり？　ボウヤ。」
- 「み～つけた♥」
- 「冗談じゃない！　お姉様から貰った大事なマントを貴女なんかに！」
- 「血も精気も吸い尽くしてあげる！　覚悟しなさい！」
- 「あんたの血も美味しそうだね。」（ボス戦イントロ）
- 「痛た・・・、もう許さないからね・・・。」（フェーズ2移行）
- 「あんたもボウヤも、吸い尽くしてやるから・・・！！」（低HP時）
- 「ああもう！　ベラドンナ様に言いつけてやる！！」（敗北）

## キャラクター上の役割

- 本作のメインボスにして最大の脅威
- ベラドンナという更に上位の存在を示唆する「番犬」的ポジション
- バッドエンドでは加害者として最も活躍する
- クリアルートでは敗北・撤退し、続編への伏線を張る
- マントを通じてベルナデットと因縁でつながっている

## 続編への伏線

- 敗北台詞「ベラドンナ様に言いつけてやる！！」
  - ベラドンナが真のラスボスとして登場する布石
  - リアラはベラドンナの使いに過ぎなかったことが明らかになる
