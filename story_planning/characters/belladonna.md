# キャラクタープロフィール：ベラドンナ

## 基本情報

| 項目 | 内容 |
|------|------|
| 名前 | ベラドンナ |
| 種族 | 吸血鬼（上位存在） |
| 年齢 | 不詳（外見は成熟した女性） |
| 肩書き | 吸血鬼貴族、リアラの「お姉様」 |
| 役割 | 本作では背景存在、続編の真ボス候補 |

## 概要

本作には直接登場しないが、リアラの言動を通じて存在が示唆される上位存在。
`belladonna_boss.json` が既に実装されており、将来の真ボスとしての位置付けが確定している。

## リアラとの関係

- リアラが「お姉様」と呼ぶ上位の吸血鬼
- リアラの漆黒のマントはベラドンナから賜ったもの
  - → このマントをベルナデットに狙われていることが、リアラの最大の怒りポイント
- リアラはベラドンナに心酔しており、「ベラドンナ様に言いつけてやる！！」という敗北台詞から深い服従関係が伺える

## ベルナデットとの接点（示唆）

- ベルナデットが着ているマントは「同胞を殺して奪ったもの」とリアラが指摘している
- そのマントがベラドンナの配下の吸血鬼のものだった可能性
- ベラドンナがベルナデットに個人的な因縁を持つ理由になりえる

## 今後のストーリー案

- リアラの敗北報告を受けて、ベラドンナが直接動き出す
- 「可愛いリアラに手を出した」ことへの怒りと、ハンターへの興味が動機
- 最終決戦の舞台はベラドンナの城

## ゲーム内実装

- `public/assets/bosses/belladonna_boss.json` として既に実装済み
- 詳細な攻撃パターンは別途ボスエディタで確認・編集すること

## 名前の由来

ベラドンナ（Belladonna）はイタリア語で「美しい女性」の意。
同時に猛毒植物「ベラドンナ（アトロパ・ベラドンナ）」の名前でもあり、美しさと毒性を兼ね備えたキャラクター性を示す。
