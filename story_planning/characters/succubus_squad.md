# サキュバス隊：キャラクター設定集

## 概要

リアラ配下のサキュバス軍団。Village_mapの制圧・村人からの精気吸収・見張りを担当。
ストーリーには直接絡まないが、村の雰囲気を作る重要な存在。
各自が個性を持ち、NPC台詞や戦闘台詞で個性が出るようにする。

全員リアラへの忠誠心はあるが、その表れ方はバラバラ。

## 個別プロフィール

---

### No.1 ナーシャ

**タイプ：** 天然・食いしん坊
**外見：** ふわふわした髪、ぽかんとした大きい瞳、ふくよかな体型
**性格：** 悪意はないが天然すぎて結果的に残酷なことをしている。食べることへの情熱だけは本物。

**村でのセリフ（巡回・待機）**
- 「はぁ～、おなかすいた～。　若い子の精気ってほんとにおいしいよね～♥」
- 「あれ～？　さっき捕まえた子、どこ行ったかな～？　逃がしちゃったかも～。」
- 「リアラ様って怖いけど、連れてきてくれるごちそうは毎回最高なんだよね♥」
- 「この村の男の子たち、みんなおいしそう～♥　どこから食べようかな～。」
- 「あ～眠い。ごはん食べたらまた眠くなってきた。ねむねむ～。」

**戦闘台詞**
- 「あ～！　邪魔しないでよ～！　これから食べようとしてたのに～！」
- 「え、強い・・・？　リアラ様～、助けて～！！」

### No.2 リリス

**タイプ：** 高飛車・貴族気質
**外見：** 長い巻き髪、常に澄ました表情、丁寧な衣装
**性格：** 自分が下等な存在と関わることを嫌う。しかしリアラへの忠誠心は本物。人間への蔑視が激しい。

**村でのセリフ（巡回・待機）**
- 「まったく・・・汚らしい村ね。　リアラ様のお役に立てるなら仕方ないけれど。」
- 「人間って、なんでこんなに弱いのかしら。　抵抗する気概くらい見せなさいよ。」
- 「私がこんな場所で見張りをしなければならないなんて・・・屈辱だわ。」
- 「あの男、私を見てびくびくしてたわね。　当然よ。私は高貴なサキュバスなのだから。」
- 「ハンターが来たって？　ふふ、面白いじゃない。人間のくせに生意気ね。」

**戦闘台詞**
- 「貴女が例のハンター？　思ったより大したことないわね。」
- 「私の爪を受けなさい。その程度で倒れるなら、最初から来なければよかったのよ。」

---

### No.3 メル

**タイプ：** ぐうたら・マイペース
**外見：** 半目、ぼさぼさの髪、いつでも眠そう
**性格：** 最低限の仕事しかしない。しかし戦闘になるとなぜか地力が高い。

**村でのセリフ（巡回・待機）**
- 「ふわぁ・・・見張りって眠いな・・・。」
- 「あー、また逃げた。　まあいいか、どうせ村の外に出ても死ぬだろ。」
- 「リアラ様がうるさいから一応歩いてるけど、正直ここに座りたい。」
- 「あの男、今日で三回目だったかな。　ふわぁ・・・、もういっか。」
- 「ねえ、ナーシャ。　ちょっとだけ寝てくれって言ったら怒る？」

**戦闘台詞**
- 「・・・邪魔。　さっさと終わらせて寝る。」
- 「・・・（あくびしながら攻撃）、強いじゃん。　少し目が覚めた。」

### No.4 ヴィータ

**タイプ：** 猛者・狩猟本能
**外見：** 鍛えられた体、鋭い目つき、爪が長い
**性格：** 戦いと追跡を何より愛する。逃げる獲物が一番好き。リアラを尊敬している。

**村でのセリフ（巡回・待機）**
- 「ははっ、逃げた逃げた！　そうじゃないとつまらないのよ！」
- 「この村の男、みんなすぐへたれるのよね。　もう少し走ってくれてもいいのに。」
- 「あのハンターとやら、会ってみたいな。　リアラ様より強かったりして？」
- 「村を制圧するの、簡単すぎてつまんなかったな。　次はもっと手ごたえのある所がいい。」
- 「（獲物を追いかけながら）逃げろ逃げろ～♥　もっと必死になれよ！」

**戦闘台詞**
- 「来たよ来たよ！　ちゃんと強いんでしょうね！？」
- 「いいじゃん、やろうよ！　待ってたんだよそういうの！！」

### No.5 ソフィア

**タイプ：** 温和そう・実は残酷
**外見：** おっとりした笑顔、優しそうな瞳、柔らかい雰囲気
**性格：** 常に穏やかで親切そうに振る舞う。しかしその実、誰より冷酷。言葉で人を追い詰めるのが得意。

**村でのセリフ（巡回・待機）**
- 「あら～、どうしたの？　大丈夫？　怖くないよ？　（ニコニコ）」
- 「逃げなくていいのに。　ちゃんと、優しくするから♥」
- 「あのひと、壊れちゃったね。　でもそのほうが扱いやすいし、いいよね。」
- 「リアラ様は怖いってよく言われるけど、私はそんなことないと思うな。　だって正直じゃない。」
- 「抵抗するの、見てるの好きなんだよね。　いつか諦めるから。みんなそうだから。」

**戦闘台詞**
- 「あらあら、強いんだね。　でも大丈夫、ゆっくりやるから。」
- 「痛かった？　ごめんね。　でも、もっと痛くなるよ？　（微笑み）」

### No.6 ミミ

**タイプ：** 幼い見た目・ブラック
**外見：** 小柄で童顔、ふわふわした服、あどけない表情
**性格：** 見た目は子供のようだが、実際はかなり長生きのサキュバス。気に食わないことがあると豹変する。

**村でのセリフ（巡回・待機）**
- 「ねえ、一緒に遊ぼ～？　（ニコ）」
- 「あのおじさん、ミミに触ってきたから倍返しにしてやったよ！　えへ♥」
- 「子供だと思ってバカにしてくる人、嫌い。　痛い目見せてあげたもん。」
- 「リアラ様はかっこいいなあ。　ミミも大きくなったらあんなになれるかな？」
- 「強い人間、来るんだって？　ミミ、会いたい！　いじめちゃおっと♥」

**戦闘台詞**
- 「わ！　強い！！　やばい！　・・・でも負けないも～ん！」
- 「馬鹿にしてるでしょ！？　（キレ気味）ミミ本気になったら怖いんだから！！」

### No.7 ローレン

**タイプ：** 策士・クール
**外見：** 切れ長の目、整った顔立ち、無表情に近い
**性格：** 感情を滅多に見せない。常に状況を分析して最適解を選ぶ。リアラには能力を買われているが、やや距離を置いている。

**村でのセリフ（巡回・待機）**
- 「村の西側は制圧完了。東側はあと2名。予定より遅れているわ。」
- 「ハンターが侵入したなら、リアラ様に報告するより先に逃げ道を塞ぐべきね。」
- 「感情で動く連中は使いにくい。　ヴィータ、また遊び始めた。」
- 「この村の構造、頭に入った。いつでも誘導できる。」
- 「精気の吸収効率が下がっている。　男性の恐怖レベルが飽和したのかもしれない。」

**戦闘台詞**
- 「事前に調べてある。貴女の戦闘スタイルは把握しているわ。」
- 「・・・想定の範囲外ね。　修正する。」

### No.8 エルザ

**タイプ：** 執着狂・重め
**外見：** 長い黒髪、色白、じっとりした目つき
**性格：** 一度気に入った獲物から絶対に離れない。愛情表現が重くて歪んでいる。リアラへの忠誠は「愛」に近い。

**村でのセリフ（巡回・待機）**
- 「あの子、今日も同じ場所にいる。　かわいい。　ずっと見ていたい。」
- 「逃げないで。　逃げても追いかけるだけよ。　それよりここにいて。」
- 「リアラ様・・・今日も綺麗。　ずっとそばにいたい。　でも言えない。」
- 「あの子に他のコが近づいた。　・・・だめ。あの子はわたしの。」
- 「（遠くをじっと見て）・・・まだいる。　よかった。」

**戦闘台詞**
- 「・・・邪魔しないで。　あの子のそばにいたいの。」
- 「わたしを怒らせたらどうなるか・・・わかってるよね？」

## グループダイナミクス

| 関係 | 内容 |
|------|------|
| ナーシャ ⇔ メル | よく一緒にいる。メルがナーシャの天然ぼけに付き合う |
| リリス ⇔ ヴィータ | 仲が悪い。品格vs本能でよくぶつかる |

## 実装メモ

### NPC台詞への落とし込み方

各サキュバスを `npc-defs.json` に追加し、`speechLines` と `dialogLines` を設定する。

**フォーマット例（ナーシャ）：**
```json
{
  "id": "npc_succubus_nasha",
  "name": "ナーシャ",
  "spriteKey": "succubus_nasha",
  "animated": true,
  "movement": "patrol",
  "speechLines": [
    "はぁ～、おなかすいた～♥",
    "若い子の精気ってほんとにおいしいよね～♥",
    "あれ～、さっきの子どこ行ったかな～？"
  ],
  "speechIntervalMs": 5000,
  "dialogLines": [
    "え～、邪魔しないでよ～！　これから食べようとしてたのに！"
  ]
}
```

### 実装優先度案

全員を同時に実装する必要はなく、スプライトが用意できたものから順次追加できる。
最初はスプライトを共通化して名前だけ変えるアプローチでも成立する。
