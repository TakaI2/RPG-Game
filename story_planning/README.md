## 各ストーリーの位置づけ

| ファイル | 役割 | 状態 |
|----------|------|------|
| `opening.json` | 第一部の導入 | ✅ endあり・拡充余地あり |
| `boss_story.json` | ボス戦前の煽り | ❌ **endコマンドなし・要追加** |
| `midle_end.json` | 第一部エンディング（リアラ逃走→城へ） | ✅ 完成度高い |
| `badend.json` | 敗北ルート（成人向け） | ✅ endあり・「名前」修正が必要 |
| `clear.json` | 第二部・真エンド（ベラドンナ撃破） | ❌ **中身が別世界観・丸ごと書き直し必要** |

---

## 緊急対応が必要な問題

| 優先度 | ファイル | 問題 | 対処 |
|--------|----------|------|------|
| 🔴 高 | `boss_story.json` | `end` コマンドがない | 末尾に `{ "op": "end" }` 追加 |
| 🔴 高 | `clear.json` | 全く別の世界観（魔女・勇者） | 丸ごと書き直し（第二部実装まで保留も可） |
| 🟡 中 | `opening.json` | 「名前」がリアラのプレースホルダー（1箇所） | `"name": "リアラ"` に修正 |
| 🟡 中 | `badend.json` | 同上（2箇所） | `"name": "リアラ"` に修正 |
| 🟢 低 | 全ストーリー | 背景・立ち絵・BGMなし | `bg` / `portrait.show` / `bgm.play` 追加 |

## ストーリーの核心テーマ

- **ベルナデットのマント**：吸血鬼殺しの証、リアラの怒りの源、ベラドンナとの因縁の糸口
- **ルーネの父親**：サキュバスの犠牲者。ルーネが戦う理由。midle_endで判明
- **ベラドンナ**：全ての黒幕。リアラの「お姉様」。第二部で対決
